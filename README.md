# Speech Emotion Recognition

Учебный проект по классификации выраженных в речи эмоций на датасете RAVDESS. Используется небольшая 2D CNN на log-Mel спектрограммах.

## Статус

Реализованы подготовка данных, обучение CNN, выбор модели по validation macro F1 и оценка на test. Обучение и сохранение модели проверены на NVIDIA RTX 4070.

Следующие этапы — предсказание для отдельного WAV-файла и интерфейс Streamlit.

## Окружение

Проверенная среда: WSL2, Ubuntu 26.04, Python 3.11.16, TensorFlow 2.21.0, Keras 3.15.1.

Все команды выполняются из корня проекта в терминале Bash внутри WSL.

## Установка

Предварительно установите uv и драйвер NVIDIA для Windows с поддержкой WSL2.

```bash
git clone https://github.com/twzuka/speech-emotion-recognition.git
cd speech-emotion-recognition

uv python install 3.11.16
uv venv --python 3.11.16
uv pip sync --python .venv/bin/python requirements.txt
uv pip check --python .venv/bin/python
```

В каждом новом терминале активируйте окружение и пути к библиотекам GPU:

```bash
source activate_gpu.sh
python -c "import tensorflow as tf; print(tf.config.list_physical_devices('GPU'))"
```

Обучение требует доступного GPU. Прямые зависимости перечислены в `requirements.in`, точные версии закреплены в `requirements.txt`.

## Датасет

Используется речевая часть [RAVDESS](https://zenodo.org/records/1188976): архив `Audio_Speech_Actors_01-24.zip`.

- 1440 WAV-файлов;
- 24 диктора;
- 8 эмоций;
- актёрская речь на английском языке;
- исходная частота дискретизации — 48 кГц, разрядность — 16 бит.

Порядок классов задан в `config/settings.json`:

| Метка | Эмоция |
|---|---|
| 0 | neutral |
| 1 | calm |
| 2 | happy |
| 3 | sad |
| 4 | angry |
| 5 | fearful |
| 6 | disgust |
| 7 | surprised |

Разделение закреплено в `config/splits.json`. Дикторы между выборками не пересекаются.

| Выборка | Дикторы | Записи | Назначение |
|---|---|---|---|
| train | 01–16 | 960 | Обучение |
| validation | 17–20 | 240 | Выбор модели |
| test | 21–24 | 240 | Оценка качества |

### Загрузка

Создайте каталог и сохраните в него архив со страницы датасета:

```bash
mkdir -p data/raw
```

Ожидаемый путь — `data/raw/Audio_Speech_Actors_01-24.zip`.

Проверьте контрольную сумму:

```bash
printf '%s\n' 'bc696df654c87fed845eb13823edef8a  data/raw/Audio_Speech_Actors_01-24.zip' | md5sum -c
```

После результата `OK` распакуйте архив:

```bash
python -m zipfile -e data/raw/Audio_Speech_Actors_01-24.zip data/raw/ravdess
```

## Подготовка данных

В активированном окружении выполните:

```bash
python src/create_metadata.py
python src/analyze_data.py
python -m src.prepare_data
```

Результаты:

- `data/processed/metadata.csv` — метаданные записей;
- `reports/figures/train_data_overview.png` — анализ обучающей выборки;
- `data/processed/train.npz`, `validation.npz`, `test.npz` — подготовленные выборки.

### Предобработка

Конвейер реализован в `src/preprocessing.py`.

| Параметр | Значение |
|---|---|
| Частота дискретизации | 16 000 Гц |
| Каналы | Моно |
| Длительность | 5 секунд |
| Mel-полосы | 64 |
| FFT / шаг окна | 1024 / 256 |
| Диапазон log-Mel | 80 дБ относительно максимума записи |
| Масштаб признаков | `[0, 1]` |
| Форма одного входа | `(64, 313, 1)` |
| Seed | 42 |

Короткие записи дополняются нулями справа, длинные обрезаются до первых пяти секунд. Автоматическое удаление тишины не применяется.

Архивы NPZ содержат признаки `X`, метки `y`, порядок эмоций, номера дикторов, пути исходных файлов и снимок настроек предобработки. Признаки имеют тип `float32`, метки — `int64`.

## Модель

Архитектура описана в `src/model.py`:

- случайные сдвиги спектрограмм только при обучении;
- три блока Conv2D и MaxPooling2D с 32, 64 и 128 фильтрами;
- усреднение по времени и Flatten;
- Dense с 64 нейронами;
- Dropout 0.5;
- выход Softmax на 8 классов.

Количество параметров — 158 792.

## Обучение

Для конфигурации выбранной модели используются веса классов, рассчитанные только по train:

```bash
python -m src.train --balance-classes
```

Веса: `neutral` — 1.875, остальные классы — 0.9375. Без флага `--balance-classes` обучение выполняется без весов классов.

Основные параметры заданы в `config/training.json`:

| Параметр | Значение |
|---|---|
| Оптимизатор | Adam |
| Начальная learning rate | 0.001 |
| Максимум эпох | 150 |
| Batch size | 32 |
| EarlyStopping | Validation macro F1, patience 25 |
| ReduceLROnPlateau | Validation loss, factor 0.5, patience 8 |
| Минимальная learning rate | 0.00001 |

Каждый запуск создаёт отдельный каталог `models/<run_id>/`:

| Файл | Содержимое |
|---|---|
| `best.keras` | Модель с максимальным validation macro F1 |
| `history.csv` | Метрики по эпохам |
| `run_info.json` | Настройки запуска и сведения о выбранной эпохе |

Скрипт проверяет соответствие выборок конфигурации, отсутствие пересечения дикторов train и validation, а также загрузку сохранённой модели.

## Оценка

Выбранный запуск — `20261006-190944-469997`, лучшая эпоха — 89. Обучение завершилось после 114 эпох.

Для оценки этого запуска при наличии локально сохранённой модели:

```bash
python -m src.evaluate --run-dir models/20261006-190944-469997
```

После нового обучения укажите каталог, выведенный скриптом обучения.

Результаты сохраняются в `reports/<run_id>/`:

- `test_metrics.json`;
- `classification_report.txt`;
- `confusion_matrix.png`.

| validation | 55.00% | 0.5343 |

## Проверки

```bash
python -m pytest -q
```

Автоматические тесты проверяют конфигурацию. При подготовке и обучении дополнительно проверяются формы и типы массивов, диапазон признаков, метки, настройки и состав дикторов. Сохранение и загрузка выбранной модели проверены.

## Ограничения

Качество распознавания умеренное и существенно различается между эмоциями. Желаемые 50% accuracy на test не достигнуты.

Во время экспериментов test оценивался для пяти вариантов CNN. Итоговая оценка не является первой слепой проверкой на ранее не просмотренной тестовой выборке.

RAVDESS содержит актёрскую речь на английском языке. Перенос результатов на естественную речь, другие языки и условия записи требует отдельной проверки. Модель классифицирует выраженную в записи эмоцию и не определяет истинное внутреннее состояние человека.
