# Распознавание эмоций по голосу

Учебный проект по ознакомительной практике в РТУ МИРЭА.

Цель — обучить небольшую свёрточную нейросеть, которая определяет
выраженную в речи эмоцию по аудиозаписи в формате WAV.

## Текущий статус

Подготовлено окружение Python, установлены основные зависимости,
созданы и проверены файлы конфигурации.

Датасет пока не загружен. Обработка аудио, обучение нейросети
и демонстрационное приложение находятся в разработке.

## План проекта

- Датасет: RAVDESS, речевые записи 24 дикторов.
- Модель: небольшая 2D CNN на log-Mel спектрограммах.
- Основная метрика качества: macro F1-score.
- Интерфейс: Streamlit с загрузкой WAV-файла.
- Результат предсказания: название эмоции и вероятности всех классов.

## Настройки

- Python: 3.11.16.
- Частота аудио после передискретизации: 16000 Гц.
- Seed: 42.
- Эмоции: neutral, calm, happy, sad, angry, fearful,
  disgust, surprised.

Разделение выполняется по дикторам:

| Выборка | Дикторы |
|---|---|
| train | 01–16 |
| validation | 17–20 |
| test | 21–24 |

Записи одного диктора принадлежат только одной выборке.
Тестовая выборка не используется для подбора параметров.

## Структура

- `config/` — настройки и разделение по дикторам.
- `data/raw/` — исходные аудиозаписи.
- `data/processed/` — обработанные данные и спектрограммы.
- `models/` — сохранённая нейросеть и её контрольные точки.
- `notebooks/` — исследование данных.
- `reports/figures/` — графики.
- `src/` — код проекта.
- `tests/` — автоматические проверки.
- `requirements.in` — список прямых зависимостей.
- `requirements.txt` — зафиксированные версии зависимостей.

Данные, сохранённая нейросеть и виртуальное окружение исключены из Git.

## Подготовка окружения

Команды выполняются из корня проекта в Ubuntu через WSL.
Необходимо предварительно установить uv.

```bash
uv venv --python 3.11.16
uv pip sync --python .venv/bin/python requirements.txt
uv pip check --python .venv/bin/python
```

TensorFlow/Keras будет добавлен на этапе настройки обучения CNN.

## Ограничения

RAVDESS содержит английскую речь с актёрским выражением эмоций.
Качество работы на естественной русской речи требует отдельной проверки.

Нейросеть определяет выраженную в речи эмоцию,
а не истинное внутреннее состояние человека.
