# Speech Emotion Recognition

Учебный проект по ознакомительной практике: распознавание эмоций по голосу с помощью небольшой свёрточной нейронной сети.

Планируется обучение одной 2D CNN на log-Mel спектрограммах и создание приложения Streamlit для загрузки WAV-файла и получения предсказания.

## Текущий статус

Подготовка данных завершена:

- настроены окружение, зависимости и конфигурация;
- скачан и проверен речевой датасет RAVDESS;
- сформирована таблица метаданных;
- построены графики обучающей выборки;
- реализована общая функция предобработки аудио;
- подготовлены и проверены массивы train, validation и test.

Обучение CNN, оценка качества и интерфейс пока не реализованы. TensorFlow/Keras будет добавлен на этапе настройки обучения.

## Окружение

Разработка выполняется в VS Code внутри WSL.

- версии библиотек закреплены в `requirements.txt`.

## Датасет

Используется речевая часть [RAVDESS](https://zenodo.org/records/1188976):

- архив `Audio_Speech_Actors_01-24.zip`;
- 1440 аудиозаписей;
- 24 диктора;
- восемь эмоций;
- исходная частота дискретизации — 48 000 Гц.

Классы в порядке их числовых меток:

| Метка | Эмоция |
|---|---|
| 0 | neutral |
| 1 | calm |
| 2 | happy |
| 3 | sad |
| 4 | angry |
| 5 | fearful |
| 6 | disgust |
| 7 | surprised |

### Загрузка и распаковка

Создать папку:

```bash
mkdir -p data/raw
```

Скачать речевой архив со страницы датасета и сохранить как:

```text
data/raw/Audio_Speech_Actors_01-24.zip
```

Проверить контрольную сумму:

```bash
printf '%s\n' \
  'bc696df654c87fed845eb13823edef8a  data/raw/Audio_Speech_Actors_01-24.zip' \
  | md5sum -c
```

При совпадении команда выведет `OK`.

Распаковать:

```bash
.venv/bin/python -m zipfile -e \
  data/raw/Audio_Speech_Actors_01-24.zip \
  data/raw/ravdess
```

## Разделение данных

Дикторы не пересекаются между выборками. Разделение закреплено в `config/splits.json`.

| Выборка | Дикторы | Записи |
|---|---|---|
| train | 01–16 | 960 |
| validation | 17–20 | 240 |
| test | 21–24 | 240 |

Обучение выполняется на train, подбор параметров — по validation. Test предназначен для финальной оценки.

## Подготовка данных

Запустить последовательно:

```bash

.venv/bin/python -m src.prepare_data
```

Результаты:

- `data/processed/train.npz`;
- `data/processed/validation.npz`;
- `data/processed/test.npz`.

### Предобработка

Параметры закреплены в `config/settings.json`.

| Параметр | Значение |
|---|---|
| Seed | 42 |
| Частота дискретизации | 16 000 Гц |
| Звуковые каналы | моно |
| Длительность | 5 секунд |
| Число mel-полос | 64 |
| Размер FFT | 1024 |
| Шаг между окнами | 256 |

Короткие записи дополняются нулями справа. У длинных используются первые пять секунд.

Спектрограмма мощности переводится в децибелы относительно максимума записи с диапазоном 80 дБ, затем масштабируется в `[0, 1]`. Автоматическое удаление тишины не выполняется.

Одна спектрограмма имеет размер `64 × 313`. Для CNN добавляется измерение одного канала.

### Формат массивов

| Архив | Форма X | Форма y |
|---|---|---|
| train.npz | `(960, 64, 313, 1)` | `(960,)` |
| validation.npz | `(240, 64, 313, 1)` | `(240,)` |
| test.npz | `(240, 64, 313, 1)` | `(240,)` |

Каждый архив содержит:

- `X` — спектрограммы, `float32`;
- `y` — числовые метки эмоций, `int64`;
- `emotions` — названия эмоций в порядке меток;
- `actors` — номера дикторов;
- `paths` — пути исходных WAV относительно корня проекта;
- `settings_json` — снимок настроек подготовки данных.

## Проверки

Начальные автоматические тесты:

```bash
.venv/bin/python -m pytest -q
```

Дополнительно выполнены проверки:

- обработки реальных моно- и стереозаписей;
- чтения всех трёх подготовленных архивов;
- форм и типов массивов;
- конечности признаков и диапазона `[0, 1]`;
- наличия всех восьми классов;
- соответствия сохранённых настроек конфигурации;
- отсутствия пересечений дикторов между выборками.

## Дальнейшая работа

1. Настроить TensorFlow/Keras.
2. Реализовать и обучить небольшую 2D CNN.
3. Оценить качество на тестовой выборке.
4. Создать модуль предсказания.
5. Добавить интерфейс Streamlit.

Главная метрика — macro F1-score. Дополнительно планируются accuracy, macro precision/recall, weighted F1 и матрица ошибок.

## Ограничения

RAVDESS содержит актёрские записи речи на английском языке. Будущее предсказание будет относиться к эмоциональной окраске записи и не определяет достоверно внутреннее состояние человека.
